# FRC IntelliJ IDEA Plugin

An IntelliJ IDEA plugin for FIRST Robotics Competition (FRC) robot development in Java. This plugin works with either the free open-sourced Community Edition or the licensed Ultimate Edition of IntelliJ IDEA.


## Current State
I started developing and using this plugin for my own use late in the 2016 season. I did an unpublicized ["soft release"](https://en.wikipedia.org/wiki/Soft_launch) of it for the 2017 release for some initial beta testing. Despite making no announcements of its availability, it was downloaded and used by a little over 300 users. Few issues were reported. 

After the 2017 build season and prior to the 2018 build season I made some additional improvements, bringing the plugin up to near identical feature parity with the official WPI Eclipse plugin. (The project new wizard I implemented is a bit elementary due to some time constraints, and I aim to make it far more robust in a future version.) For the 2018 season, I made a single announcement of the plugin's availability in the Chief Delphi forums. Over 1,500 additional users downloaded the plugin. During the 2018 season a few minor bugs were reported and fixed.

I continue to work on the plugin and plan to release it as a 1.0 version for the 2019 build season. 

:warning: As of v0.6 (Jan 2018), IntelliJ IDEA v2017.3 or later is required.
