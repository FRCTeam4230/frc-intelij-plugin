These files are the "heart" of the template outputs from https://www.toptal.com/developers/gitignore/api/{template} We do however remove the two header lines and the single footer line. This is so we can combine them into a single output adding the header and footer lines for the entire output.

For example, https://www.toptal.com/developers/gitignore/api/foo might generate:

[source, .gitignore]
----
# Created by https://www.toptal.com/developers/gitignore/api/foo
# Edit at https://www.toptal.com/developers/gitignore?templates=foo

### Foo ###
# Some Comment
tmp/
foo.*
bar.*

# Log files
*.log

# End of https://www.toptal.com/developers/gitignore/api/foo
----

Our `foo.txt` file would just contain:

[source,.gitignore]
----
### Foo ###
# Some Comment
tmp/
foo.*
bar.*

# Log files
*.log
----
