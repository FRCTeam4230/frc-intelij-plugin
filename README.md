# FRC IntelliJ IDEA Plugin

An IntelliJ IDEA plugin for FIRST Robotics Competition (FRC) robot development in Java. This plugin works with either the free open-sourced Community Edition or Education Edition, or the licensed Ultimate Edition of IntelliJ IDEA.

:warning: IntelliJ IDEA v2019.2 or later is required.

## Current State
The plugin is compatible with the 2019 changes make in the WPILib and the move to using Gradle. The plugin now contains a robust New Project Wizard to generate GradleRIO based projects. The 2020 beta releases were looked at to ensure compatibility as best as possible for the 2020 build season. This includes support for the new version 2 of the Command Based API.
