== VS Code install behavior

=== Offline Install

It lists all file located in the `wpilib/{frcyear}/vendordeps` directory. In the event of multiple versions, it lists them all. You can search the list, and select multiple options.

image::vscode-offline-install-screenshot.png[]

The reason version 5.19.0 of CTRE-Phoenix is seperated from the other versions, is that it is sorting by file name, not library name (in the JSON). And in the `wpilib/{frcyear}/vendordeps` directory, v5.19.0 had a different file name:

image::wpilib-vendordeps-dir.png[]

We'll need to make sure we sort by library name.
