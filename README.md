# FRC IntelliJ IDEA Plugin

An IntelliJ IDEA plugin for FIRST Robotics Competition (FRC) robot development in Java. This plugin works with either the free open-sourced Community Edition or the licensed Ultimate Edition of IntelliJ IDEA.


## Current State
**This plug-in is in beta and is not feature complete yet.** I started developing and using this plug-in for my own use in late 2016. I did a "soft release" of it for 2017 for some initial beta testing. I made some improvements after the 29017 build season. But did not get a chance to add some of the features I have in mind. Nevertheless, the current feature set mimic those in tehWPI Eclipse Plugin. For the 2018 build season, I'm running a more "formal" beta release having announced it the Chief Delphi forums. WPI made several breaking changes to the the WPI Lib for 2018. These did catch me unaware as I learned about them on kickoff day like everyone else. I have resolve the change in the deployment of the robot code to the roboRIO. But a breaking change to the way the RIOLog works (see [Issue #7](https://gitlab.com/Javaru/frc-intellij-idea-plugin/issues/7). I am close to having it resolved. In the meantime, you can use the *SSH Tailing* feature as an alternative way of monitoring the roboRIO. 

:warning: **As of v0.6 (Jan 2018), IntelliJ IDEA v2017.3 or later is required.**
